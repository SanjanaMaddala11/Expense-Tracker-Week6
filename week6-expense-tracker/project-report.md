# Week 6: Git, GitHub and Final Web Development Project Report

## 1. Objective
The objective of this project is to demonstrate version control using Git and GitHub while developing and maintaining a responsive, interactive web application.

## 2. Project Overview
The Expense Tracker is a web application developed using HTML, CSS and JavaScript. It helps users record income and expenses, monitor transactions, and understand their available balance. The project builds on the practical web development skills learned during the internship.

## 3. Technologies Used
- **HTML5:** Structures the application interface.
- **CSS3:** Styles the interface using Flexbox, Grid and media queries.
- **JavaScript:** Implements transaction management, calculations, validation, searching and filtering.
- **Git:** Tracks changes and maintains version history.
- **GitHub:** Hosts the source code and supports collaboration and version control.
- **GitHub Pages:** Hosts the deployed website.

## 4. Features Implemented
Users can add income and expense transactions with relevant details, including description, amount, category and date. The application calculates totals, supports editing and deleting transactions, and provides search and filtering options. Input validation helps prevent invalid entries. Local storage preserves transaction data between browser sessions. The responsive design adapts the interface to different screen sizes.

## 5. Git and GitHub Workflow
A separate Git repository was initialized for this submission. The project files were staged using `git add`, committed using `git commit`, and uploaded to GitHub using `git push`. Git status and commit history were used to check repository changes. A separate public repository was created for Week 6 to keep it independent of the Week 5 submission.

## 7. Challenges and Solutions
Managing Git history and separating the Week 6 repository from the existing Week 5 submission required careful handling. Creating a separate repository provided independent version control. Testing transaction operations and browser storage helped verify the main application features.

## 8. Learning Outcomes and Future Improvements
This project improved my understanding of Git commands, commits, remote repositories, HTML, CSS, JavaScript, DOM interaction and responsive design. Future improvements could include spending charts, monthly summaries, budget limits and exporting transaction records.

## Conclusion
The project demonstrates practical web development and version-control skills. It provides a foundation for further improvements and helps prepare for collaborative software development.
