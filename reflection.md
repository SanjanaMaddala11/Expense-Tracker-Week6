# Week 5 JavaScript Project Reflection

## Project Overview

For my InternNova Week 5 JavaScript project, I developed an Expense Tracker web application using HTML, CSS, and JavaScript. The purpose of this project is to help users record their income and expenses, monitor their spending, and calculate their available balance.

## Features Implemented

The application allows users to add income and expense transactions by entering a description, amount, transaction type, category, and date. The dashboard automatically calculates total income, total expenses, and the current balance. Users can also edit or delete transactions, search by description or category, and filter transactions by type.

I used browser localStorage to save transaction data so it remains available after refreshing the page. I also implemented input validation to prevent empty descriptions and invalid or non-positive amounts.

## Challenges and Solutions

One challenge was connecting JavaScript functionality to the HTML form and displaying transactions dynamically. I addressed this by using DOM manipulation and event listeners to respond to form submissions and button clicks.

Another challenge was ensuring that the income, expense, and balance values updated correctly whenever transactions changed. I used JavaScript array methods, including filter and reduce, to calculate the totals. I then implemented localStorage to preserve the transaction data between page refreshes.

Designing a responsive interface was another important part of the project. I used CSS Grid, Flexbox, spacing, and media queries to improve the layout on different screen sizes.

## Learning Outcomes

Through this project, I practised JavaScript functions, arrays, objects, DOM manipulation, event handling, form validation, and browser storage. I also improved my understanding of HTML structure, CSS styling, responsive design, and debugging.

## Future Improvements

In the future, I would like to add spending charts, monthly reports, budget limits, data export, and more detailed financial summaries.

Overall, this project helped me apply the concepts I learned during my web development internship to a practical application.
