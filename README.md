# Expense Tracker

A responsive web application built with HTML, CSS, and JavaScript to help users manage their income and expenses.

## Features

- Add income and expense transactions
- Calculate total income, total expenses, and balance automatically
- Edit and delete transactions
- Search transactions by description or category
- Filter transactions by type
- Save transaction data using browser localStorage
- Responsive layout for desktop and mobile screens
- Validate transaction details before adding them

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Add transactions using the form.
5. Use the search, filter, Edit, and Delete controls to manage transactions.
